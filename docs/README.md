# גרסת GitHub Pages — רצה ישירות מה-repo

התיקייה הזו היא אתר סטטי לחלוטין (`index.html`, `app.js`, `styles.css`). GitHub Pages מגיש אותה כמו שהיא, בלי שרת ובלי חשבון נוסף.

## הפעלה חד-פעמית

**Settings → Pages → Build and deployment → Source: _Deploy from a branch_ → Branch: `claude/multiplayer-roulette-game-msah4q` + תיקייה `/docs` → Save.**

תוך דקה-שתיים הכתובת תהיה:

## איך המשחק מסתנכרן בלי שרת

הטלפון שפותח את השולחן הוא הרשות של אותו משחק — הוא מגריל את המספר, מחשב זכיות, ומשדר את מצב השולחן כהודעה **retained** על ברוקר MQTT ציבורי דרך WSS. שאר הטלפונים נרשמים לאותו נושא (`roulette/v1/<קוד>/state`), ולכן מי שמצטרף באיחור מקבל מיד את מצב השולחן הנוכחי. פעולות של שחקן (הימור, הצטרפות) נשלחות בחזרה בנושא `.../act`.

הברוקרים בשימוש, לפי הסדר, עם נפילה אוטומטית לבא בתור: `broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`. אלה שירותי בדיקה ציבוריים וחינמיים — מצוין למשחק בין חברים, לא לנתונים רגישים.

מגבלה אחת שנובעת מהארכיטקטורה: אם הטלפון של המארח נסגר, השולחן קופא. שאר המכשירים יציגו "המארח לא משדר" אחרי ~14 שניות, ואפשר לפתוח שולחן חדש.
