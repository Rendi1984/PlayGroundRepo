# 🎰 רולטה מרובת משתתפים / Multiplayer Roulette

משחק רולטה בזמן אמת שאפשר לשחק משני טלפונים (ויותר) במקביל.
ללא תלויות חיצוניות — Node.js בלבד.

## הפעלה

```bash
cd roulette
npm start            # ברירת מחדל: http://localhost:3000
PORT=8080 npm start  # פורט אחר
```

## חיבור משני טלפונים

השרת מאזין על כל כרטיסי הרשת, לכן:

1. ודאו ששני הטלפונים באותה רשת Wi-Fi כמו המחשב שמריץ את השרת.
2. מצאו את כתובת ה-IP של המחשב (`ipconfig` בווינדוס / `ip addr` בלינוקס / `ifconfig` ב-macOS).
3. בטלפון הראשון פתחו `http://<IP>:3000`, הזינו שם ולחצו **פתיחת חדר חדש** — יתקבל קוד בן 4 תווים.
4. לחצו על **שיתוף** כדי לשלוח לינק ישיר (`/?code=XXXX`) לטלפון השני, או הקלידו שם את הקוד ולחצו **הצטרפות לחדר**.

לשחק מרשתות שונות: פרסו את הפרויקט לכל שרת Node (Render / Railway / Fly / VPS) או השתמשו במנהרה זמנית (`ngrok http 3000`).

## מהלך המשחק

- כל שחקן מתחיל עם 1000 ז'טונים. מקסימום 8 שחקנים בחדר.
- המארח (👑) לוחץ **התחלת סיבוב** ונפתח חלון הימורים של 20 שניות (ניתן לקצר עם **סובב עכשיו**).
- הימורים: מספר בודד (35:1), אדום/שחור, זוגי/אי-זוגי, 1-18 / 19-36 (1:1), תריסרים (2:1).
- הגלגל מסתובב 6 שניות, התוצאה והזכיות מתעדכנות אצל כל השחקנים בו-זמנית, וסיבוב חדש מתחיל אוטומטית.
- שחקן שנשאר בלי ז'טונים מקבל 100 ז'טונים כדי להמשיך לשחק.

## תמיכה בדפדפנים

מותאם למובייל (RTL, אזורי לחיצה גדולים, `safe-area` ל-iPhone עם notch), ונבדק מול היכולות הבאות בלבד — כולן נתמכות ב-Chrome / Firefox / Samsung Internet באנדרואיד וב-Safari / Chrome ב-iOS (מגרסה 12.2 ומעלה):

| יכולת | שימוש |
|---|---|
| `EventSource` (SSE) | עדכונים בזמן אמת מהשרת |
| `fetch` + JSON | שליחת פעולות |
| CSS Grid / Flexbox / `conic-gradient` | פריסה וגלגל הרולטה |
| `navigator.share` / `clipboard` | שיתוף קוד החדר (עם נפילה חיננית לטקסט) |

אין שימוש ב-WebSocket, ולכן החיבור עובד גם דרך proxy-ים ורשתות שחוסמות שדרוג פרוטוקול. חיבור שנקטע (נעילת מסך, מעבר לאפליקציה אחרת) מתחבר מחדש אוטומטית, והמושב נשמר ב-`localStorage`.

## מבנה

```
roulette/
├── server.js          # HTTP + SSE, לוגיקת חדרים, הגרלה ותשלומים (ללא תלויות)
└── public/
    ├── index.html
    ├── styles.css
    └── app.js
```

כל לוגיקת המשחק (הגרלת המספר עם `crypto.randomInt`, בדיקת יתרה, חישוב זכיות) רצה בשרת בלבד — הלקוח לא יכול לשנות יתרה או תוצאה.
