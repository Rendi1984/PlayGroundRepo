# גלגל הזוגות — גרסת שני טלפונים (GitHub Pages)

אתר סטטי לחלוטין (`index.html`, `app.js`, `tasks.js`, `styles.css`) שרץ ישירות מה-repo, בלי שרת.

## הפעלה חד-פעמית

**Settings → Pages → Source: _Deploy from a branch_ → Branch: `claude/multiplayer-roulette-game-msah4q` + תיקייה `/docs` → Save**, ואז:

```
https://rendi1984.github.io/PlayGroundRepo/
```

טלפון אחד פותח שולחן ומקבל קוד בן 4 תווים, השני מצטרף דרך כפתור **שיתוף** או בהקלדת הקוד.

## המשחק

הגלגל נפתח עם **8 משבצות, כל אחת משימה אחת** מקטגוריה אחרת — נשיקה, ידיים, לחישה, הפשטה, פה, שליטה, אתגר, בחירה. אחרי כל סיבוב המשבצת שנחתה עליה יורדת מהגלגל, כך שהוא מתקצר 8 → 7 → 6 … → 1, וכשהוא מתרוקן נחלק גלגל חדש מהמשימות שנשארו. **בוצע** מזכה בנקודה ומוציא את המשימה מהמשחק לתמיד; **דלגו** מוריד אותה מהגלגל הנוכחי בלבד, והיא עשויה לחזור בגלגל הבא. אחרי 64 משימות מופיע מסך סיום עם התחלה מחדש.

רמה אחת בלבד — **בלי גבולות** — ואין בורר רמות. כל המשימות באותה בריכה מהסיבוב הראשון.

## תפריט סודי

עשר הקשות על שורת החיבור שבתחתית המסך (או על מספר הגרסה) פותחות תפריט נסתר. אין לו כפתור, קישור או רמז ויזואלי — רק הרצף עצמו, ורק בטלפון שהקיש; בן/בת הזוג לא רואים כלום. הפסקה של יותר משתי שניות בין הקשות מאפסת את הספירה.

מה יש בו: החזרת כל המשימות לגלגל, העברת התור לצד השני, כתיבת משימה משלכם (נכנסת לגלגל, ומקבלת עדיפות בחלוקה הבאה), ובחירת משימה ידנית מתוך הרשימה המלאה. בתחתית מוצגים קוד השולחן, הגרסה וכמה משימות בוצעו.

כל עוד התפריט פתוח, עדכוני הרקע (פעימת הלב כל 4 שניות, ופעולות של בן/בת הזוג) **מוחזקים ולא מרנדרים מחדש** — אחרת רשימת הבחירה הייתה נסגרת באמצע גלילה, במיוחד בדפדפן במחשב. הם מוחלים בבת אחת ברגע שסוגרים את התפריט. הבחירה עצמה נשמרת גם אם כן מתרחש רינדור.

## גרסה

מספר הגרסה מוצג בתחתית המסך, מתחת לשורת החיבור, ויושב במקום אחד: `docs/version.js`. שתי הגרסאות — שני הטלפונים וטלפון אחד — קוראות משם, כך שאין סיכוי שיציגו מספרים שונים.

**בכל שינוי שנדחף מעדכנים את `APP_VERSION` שם**, ואז מריצים `python3 tools/build-artifact.py` כדי שגרסת טלפון אחד תיבנה מחדש עם המספר המעודכן. כך אפשר לדעת מהמסך אם הטלפון באמת קיבל את הגרסה האחרונה או שהדפדפן מגיש עותק מטמון.

## קול

`sound.js` מסנתז את הקול ב-Web Audio, בלי קבצי אודיו וללא הורדות. הטיקים מתוזמנים לפי אותה עקומת האטה של האנימציה (`cubic-bezier(.13,.72,.14,1)`), כך שהמרווח ביניהם גדל מ-61ms ל-170ms במהלך הסיבוב והם נעצרים בדיוק כשהגלגל נעצר, ואז נשמע צליל נחיתה. הקול מופעל בתוך לחיצת הכפתור — התנאי של iOS לשחרור אודיו. כפתור 🔊 בשורה העליונה משתיק, וההעדפה נשמרת. דפדפן בלי Web Audio פשוט שקט, בלי שגיאה.

## חזרה לדף

המכשיר זוכר את השולחן ב-`localStorage`, כך שרענון או סגירת הדפדפן לא מוציאים אתכם מהמשחק — הדף חוזר לאותו שולחן ולאותו מצב. מי שפתח את השולחן מאמץ בחזרה את המצב מההודעה ה-retained שהוא עצמו שידר. ליציאה מכוונת יש כפתור **יציאה** ליד קוד השולחן.

## ניסוח בעברית

כל שחקן בוחר בכניסה לשון זכר או נקבה, וכל משימה נכתבת ביחיד ומוטה בזמן אמת:

| סימון | נוטה לפי | דוגמה |
|---|---|---|
| `{זכר\|נקבה}` | מי שמבצע/ת | `{נשק\|נשקי}` |
| `[זכר\|נקבה]` | בן/בת הזוג | `[הוא מבקש\|היא מבקשת]` |
| `{you}` `{them}` | השמות עצמם | |

כך `'{נשק|נשקי} את {them} עד ש[הוא מבקש|היא מבקשת] עוד'` יוצא "נשקי את דן עד שהוא מבקש עוד" או "נשק את מיה עד שהיא מבקשת עוד". כל ארבעת הצירופים (זכר-נקבה, נקבה-זכר, זכר-זכר, נקבה-נקבה) נבדקים ויוצאים תקינים.

לעריכת התוכן: `tasks.js`, כל משימה היא `{ level, text }`.

## תאימות

מותאם לטלפונים ולמחשב, ונבדק מול היכולות שבהן הוא משתמש — כולן נתמכות ב-Safari ו-Chrome ב-iOS, וב-Chrome / Edge / Firefox / Samsung Internet באנדרואיד ובדסקטופ:

| יכולת | לשם מה | הערה |
|---|---|---|
| WebSocket (WSS) | הסנכרון בין הטלפונים | דרך ספריית MQTT |
| Canvas 2D | ציור הגלגל | |
| Web Audio | קול הסיבוב | `webkitAudioContext` לספארי, ושקט אם אין תמיכה |
| `localStorage` | שמירת השולחן והמשחק | עטוף ב-try/catch — גלישה פרטית בספארי זורקת חריגה |
| `navigator.share` | שיתוף הלינק | נפילה ל-clipboard ואז לטקסט |
| CSS Grid / `aspect-ratio` / `dvh` | הפריסה | `100vh` כגיבוי לדפדפנים בלי `dvh` |

פרטים שנעשו במיוחד בשביל מובייל: `touch-action: manipulation` מבטל את השהיית ה-double-tap (קריטי לרצף עשר ההקשות), שדות קלט ב-16px כדי שספארי לא יזום בפוקוס, `-webkit-text-size-adjust` כדי שספארי לא ישנה גדלים לבד, ו-`safe-area-inset` לאייפונים עם notch. במחשב הגלגל גדל, ויש מצבי hover רק למכשירים עם עכבר (`@media (hover:hover)`).

## הסנכרון

הטלפון שפותח את השולחן הוא הרשות: הוא מגריל את הקטגוריה והמשימה, מחשב את זווית העצירה, ומשדר את מצב המשחק כהודעת **retained** על ברוקר MQTT ציבורי דרך WSS. הטלפון השני נרשם לאותו נושא, מקבל את מצב השולחן מיד גם אם הצטרף באיחור, ומריץ בדיוק את אותה אנימציה — שני הגלגלים עוצרים על אותה משימה. פעולות של השחקן השני (הצטרפות, סיבוב, בוצע/דלג, שינוי רמה) נשלחות בנושא `.../act`.

ברוקרים, לפי הסדר, עם נפילה אוטומטית: `broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`. שירותי בדיקה ציבוריים — מצוין למשחק, לא לנתונים רגישים.

## נוכחות

לצד כל שם יש נקודה: ירוקה = מחובר/ת עכשיו, אדומה = נותק/ה. מתחת לגלגל כתוב במפורש "‎<שם> מחובר/ת" או "רק אתם בשולחן". כל עוד אתם לבד, מוצג חלון המתנה עם הקוד בגדול וכפתור שליחת לינק — הוא נעלם ברגע שהמכשיר השני מצטרף.

מאחורי הקלעים: המכשיר המצטרף משדר ping כל 5 שניות, והמכשיר שפתח את השולחן משדר את מצב השולחן כל 4 שניות ומסמן כמנותק מי שלא נשמע 14 שניות. אם הטלפון שפתח את השולחן נסגר, המשחק קופא והשני יראה "השולחן לא משדר".
