## המשחק

הגלגל מחולק לשמונה קטגוריות — נשיקה, ידיים, לחישה, הפשטה, פה, שליטה, אתגר, בחירה. הוא נוחת על אחת מהן ושולף ממנה משימה. **בוצע** מזכה בנקודה, מעביר תור, ו**מוריד את המשימה מהגלגל לתמיד**; **דלגו** רק מעביר תור והמשימה נשארת בבריכה. משבצת שהתרוקנה מוצגת אפורה והגלגל לא נוחת עליה יותר. אחרי 64 משימות מופיע מסך סיום עם כפתור התחלה מחדש.

ארבע רמות חום — חימום / מתחמם / לוהט / בלי גבולות. **החוגה עולה לבד**: שני סיבובים לכל רמה, כך שהמשחק נפתח בנשיקות ומגיע לרמה הגבוהה תוך שבעה סיבובים. נגיעה בחוגה מבטלת את הטיפוס האוטומטי ומקבעת את הרמה. ברמות 1–2 המשימות מצטברות, ומרמה 3 ומעלה הגלגל מפסיק לשלוף את הרכות.

## ניסוח בעברית

כל שחקן בוחר בכניסה לשון זכר או נקבה, וכל משימה נכתבת ביחיד ומוטה בזמן אמת:

| סימון | נוטה לפי | דוגמה |
|---|---|---|
| `{זכר\|נקבה}` | מי שמבצע/ת | `{נשק\|נשקי}` |
| `[זכר\|נקבה]` | בן/בת הזוג | `[הוא מבקש\|היא מבקשת]` |
| `{you}` `{them}` | השמות עצמם | |

כך `'{נשק|נשקי} את {them} עד ש[הוא מבקש|היא מבקשת] עוד'` יוצא "נשקי את דן עד שהוא מבקש עוד" או "נשק את מיה עד שהיא מבקשת עוד". כל ארבעת הצירופים (זכר-נקבה, נקבה-זכר, זכר-זכר, נקבה-נקבה) נבדקים ויוצאים תקינים.

לעריכת התוכן: `tasks.js`, כל משימה היא `{ level, text }`.

## הסנכרון

הטלפון שפותח את השולחן הוא הרשות: הוא מגריל את הקטגוריה והמשימה, מחשב את זווית העצירה, ומשדר את מצב המשחק כהודעת **retained** על ברוקר MQTT ציבורי דרך WSS. הטלפון השני נרשם לאותו נושא, מקבל את מצב השולחן מיד גם אם הצטרף באיחור, ומריץ בדיוק את אותה אנימציה — שני הגלגלים עוצרים על אותה משימה. פעולות של השחקן השני (הצטרפות, סיבוב, בוצע/דלג, שינוי רמה) נשלחות בנושא `.../act`.

ברוקרים, לפי הסדר, עם נפילה אוטומטית: `broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`. שירותי בדיקה ציבוריים — מצוין למשחק, לא לנתונים רגישים.

## נוכחות

לצד כל שם יש נקודה: ירוקה = מחובר/ת עכשיו, אדומה = נותק/ה. מתחת לגלגל כתוב במפורש "‎<שם> מחובר/ת" או "רק אתם בשולחן". כל עוד אתם לבד, מוצג חלון המתנה עם הקוד בגדול וכפתור שליחת לינק — הוא נעלם ברגע שהמכשיר השני מצטרף.

מאחורי הקלעים: המכשיר המצטרף משדר ping כל 5 שניות, והמכשיר שפתח את השולחן משדר את מצב השולחן כל 4 שניות ומסמן כמנותק מי שלא נשמע 14 שניות. אם הטלפון שפתח את השולחן נסגר, המשחק קופא והשני יראה "השולחן לא משדר".
