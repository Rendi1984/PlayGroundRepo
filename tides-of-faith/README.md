# גאות האמונה — Tides of Faith

משחק אלוהים (god game) מקורי, קובץ HTML יחיד, בלי תלויות. פותחים את `index.html` בדפדפן ומשחקים.

## מנגנונים
- **אמונה ← מאנה:** כפרים שמאמינים בך מתפללים ומייצרים מאנה. ניסים אפשר להטיל רק בתוך תחום ההשפעה (הטבעת המקווקוות).
- **5 ניסים:** גשם, שפע, ריפוי (מעוררים אהבה) · אש, ברק (מעוררים פחד, וגם פחד הוא אמונה).
- **ציר יצירה/הרס:** משנה את מחיר הניסים, את צבע העולם, הגגות והמקדש, ואת מראה הרוח.
- **נוגה, הרוח השומרת:** מתעדת כל נס שהטלת ואת ההקשר שלו (שריפה, כפר רעב, כפר יריב…). אחרי שתי חזרות היא מתחילה לפעול לבד. שבח (`Z`) מחזק את ההרגל, נזיפה (`X`) מחלישה אותו.
- **צל-המים, האל היריב:** בינה מלאכותית שמתחרה על הכפרים, מגינה על שלה, ונעשית תוקפנית יותר עם הזמן.
- סימולציה: תושבים חוטבים עצים ואוספים מזון, בונים בתים וגדלים. אש מתפשטת ביער, גשם מכבה אותה ומצמיח מחדש. יש גם מחזור יום ולילה.

## שליטה
