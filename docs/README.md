# גלגל הזוגות — גרסת שני טלפונים (GitHub Pages)

אתר סטטי לחלוטין (`index.html`, `app.js`, `tasks.js`, `styles.css`) שרץ ישירות מה-repo, בלי שרת.

## הפעלה חד-פעמית

**Settings → Pages → Source: _Deploy from a branch_ → Branch: `claude/multiplayer-roulette-game-msah4q` + תיקייה `/docs` → Save**, ואז:

```
https://rendi1984.github.io/PlayGroundRepo/
```

טלפון אחד פותח שולחן ומקבל קוד בן 4 תווים, השני מצטרף דרך כפתור **שיתוף** או בהקלדת הקוד.

## המשחק

הגלגל מחולק לשמונה קטגוריות — נשיקה, מגע, לחישה, ריקוד, מילים, פינוק, אתגר, בחירה. הוא נוחת על אחת מהן ושולף ממנה משימה, עם השמות שלכם משובצים בתוכה. **בוצע** מזכה בנקודה ומעביר תור, **דלגו** רק מעביר תור.

שלוש רמות חום — רומנטי / שובב / לוהט — משותפות לשני הטלפונים. רמה גבוהה מוסיפה משימות, לא מחליפה: ב"לוהט" עדיין יוצאות גם הרכות.

לעריכת התוכן: `tasks.js`. כל משימה היא `{ level, text }`, ובתוך הטקסט `{you}` ו-`{them}` מוחלפים בשמות בזמן אמת.

## הסנכרון

הטלפון שפותח את השולחן הוא הרשות: הוא מגריל את הקטגוריה והמשימה, מחשב את זווית העצירה, ומשדר את מצב המשחק כהודעת **retained** על ברוקר MQTT ציבורי דרך WSS. הטלפון השני נרשם לאותו נושא, מקבל את מצב השולחן מיד גם אם הצטרף באיחור, ומריץ בדיוק את אותה אנימציה — שני הגלגלים עוצרים על אותה משימה. פעולות של השחקן השני (הצטרפות, סיבוב, בוצע/דלג, שינוי רמה) נשלחות בנושא `.../act`.

ברוקרים, לפי הסדר, עם נפילה אוטומטית: `broker.emqx.io`, `broker.hivemq.com`, `test.mosquitto.org`. שירותי בדיקה ציבוריים — מצוין למשחק, לא לנתונים רגישים.

אם הטלפון שפתח את השולחן נסגר, המשחק קופא והשני יראה "השולחן לא משדר" אחרי ~16 שניות.
